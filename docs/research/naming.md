# Naming and related tools

Research date: 2026-11-12. This is a preliminary collision search, not legal trademark clearance.

* Agent X-Ray: existing [AgentXRay session viewer](https://github.com/alloevil/AgentXRay), @alloevil/agent-xray npm package, and [agent-xray on PyPI](https://pypi.org/project/agent-xray/) make the working name confusing.
* Agent Optic: existing [agent-optic](https://github.com/Kristoffer88/agent-optic) and npm package inspect sessions/transcripts; avoid this name.
* Agent Sightline: exact npm agent-sightline, PyPI agent-sightline and crates.io agent-sightline endpoints returned 404 at development time. GitHub name search returned three differently named repositories (sightline-agent, sightline-agentic, sightline-visual-agent-reliability-lab), no exact agent-sightline. CLI command was not found on the local PATH. Search again before public publication.

The core product is distinguished by static effective configuration with provenance, not session trace visualization. Related tools include Claude’s built-in /doctor prompt audit (model-assisted), configuration sync managers, and instruction format generators. Sightline focuses on reproducible, offline, deterministic loading explanations across clients.

No user counts, hosted benchmark claims or compatibility claims from other tools are used as evidence for this project.

An exact-name web/trademark search did not establish an Agent Sightline registration. The base word Sightline is widely used, including software/security brands and a Mac capture app. Agent Sightline is the selected product name. This preliminary search records the naming decision and its evidence.
