Good questions.

Does Sightline change my configuration?

Scans and the inspector are read-only. You receive source locations and suggestions, then choose how to edit your configuration in your own editor.

Can it inspect a running agent session?

Sightline models a fresh session launched in the target file’s directory. It resolves the local configuration it can inspect. Runtime toggles, extra command-line flags and remote policies can change a particular session.

Do I need my agents installed?

You can inspect configuration without installing its client. The inspector marks missing executables and checks extension commands against your local PATH.

What does “conditional” mean?

Some sources depend on workspace trust, MCP approval or a runtime decision. Sightline keeps those visible and shows what condition must be met. The trust selector lets you model a trusted or untrusted workspace.

Can I use it in CI?

Yes. Run agent-sightline ci --no-user --fail-on warn for repository-only diagnostics with a stable JSON report and an exit code determined by the finding threshold.

Does it start my MCP servers or run hooks?

The default scan checks local definitions and executable discovery. An explicit doctor --probe starts local stdio MCP servers for initialization and tools listing. Hook commands and MCP tools are never invoked by the scan.
